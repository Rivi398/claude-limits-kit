# claude-limits-kit

**Перестань упираться в лимиты Claude Max.** Три маленьких инструмента для Claude Code: понять,
куда уходят лимиты, закрыть главную утечку и видеть остаток прямо в редакторе.

[English](README.md) · MIT

| | Что делает |
|---|---|
| [`claude-usage-audit`](bin/claude-usage-audit) | Читает локальные журналы Claude Code и показывает, куда уходит расход: субагенты или основной чат, вызовы с огромным контекстом, самые тяжёлые сессии, инструменты, которые раздувают контекст. Только метаданные. |
| [`subagent-context-budget.py`](hooks/subagent-context-budget.py) | Хук PreToolUse: останавливает субагента, когда его контекст перевалил за 250k токенов, и заставляет передать работу новому. |
| [Расширение VS Code](vscode/) | Настоящие лимиты на 5 часов и на неделю, с временем сброса, в строке состояния. |

## Откуда это взялось

Каждый шаг агента перечитывает весь его контекст. Субагент, который разросся до 400–960k токенов,
платит за этот контекст на каждом вызове инструмента. Когда в сентябре 2026 мы разобрали неделю
своих журналов, оказалось, что **85% всего расхода давали субагенты**. С хуком на свежей неделе
у субагентов **1,6%**.

У тебя картина может быть другой. Сначала запусти аудит и посмотри, что съедает лимиты у тебя.

## Установка

Нужны Python 3 и Node.js (если стоит Claude Code, они обычно уже есть).

```bash
git clone https://github.com/Rivi398/claude-limits-kit
cd claude-limits-kit
scripts/install.sh
```

Скрипт копирует хук в `~/.claude/hooks/`, прописывает его в `~/.claude/settings.json` (сначала
сохраняет резервную копию, дважды не добавляет) и кладёт `claude-usage-audit` в `~/.local/bin/`.
После установки перезапусти открытые сессии Claude Code.

Расширение VS Code: скачай `claude-limits-statusbar-x.y.z.vsix` в
[Releases](https://github.com/Rivi398/claude-limits-kit/releases) и выполни

```bash
code --install-extension claude-limits-statusbar-1.0.0.vsix
```

## Аудит расхода

```
$ claude-usage-audit --days 7
  sessions                  211
  API calls                 35799
  context re-read           11381.8M tokens
  ...by subagents           1.6%
  ...by calls with 150k+    92.4%  (77.3% of calls)
```

- **context re-read**: сумма размеров контекста по всем вызовам. Лучшая локальная оценка того,
  что съедает лимиты, но не официальная цифра Anthropic.
- Высокая доля **by subagents**: ставь хук.
- Высокая доля **calls with 150k+**: дорого обходятся длинные основные сессии. Начинай новую
  сессию чаще и передавай короткую сводку вместо всей истории.
- Сверху в списке инструментов то, что забивает контекст: чтение больших файлов, скриншоты,
  снимки страниц.

`--json` выдаёт тот же отчёт в JSON. Аудит читает `~/.claude/projects/*.jsonl`, не печатает
текст сообщений, промпты, аргументы и вывод инструментов и ничего не отправляет в сеть.

## Хук бюджета контекста

Срабатывает перед каждым вызовом инструмента. В основном чате ничего не делает. В субагенте:

- с **200k** токенов напоминает агенту закругляться с текущим шагом;
- с **250k** запрещает любые инструменты: агент заканчивает отчётом для передачи (что сделано,
  что осталось, какие файлы трогал, что прочитать первым), а оркестратор продолжает **новым**
  субагентом вместо того, чтобы кормить раздутого.

Субагент, который *стартовал* большим (форк длинного чата), получает такой же запас сверх старта.

Пороги меняются переменными `CLAUDE_SUBAGENT_CTX_WARN` и `CLAUDE_SUBAGENT_CTX_HARD` (в токенах).
Приостановить: `touch ~/.claude/context-budget-off`, вернуть: удалить этот файл.
Внутренние ошибки хук глотает, поэтому работу он не заблокирует.

## Расширение VS Code

Показывает в строке состояния `5ч 34% · 7д 61%`. При наведении видно время сброса, клик обновляет.
С 90% надпись краснеет. Язык русский или английский, как в VS Code.

Расширение берёт OAuth-токен, который уже сохранил Claude Code (связка ключей macOS или
`~/.claude/.credentials.json` в Linux и Windows), и обращается к тому же адресу, что и команда
`/usage` в Claude Code. Токен уходит только на `api.anthropic.com`. Это не документированный
публичный API, он может измениться; тогда расширение покажет «нет данных», ничего не сломав.
Обновляется раз в 5 минут (адрес пускает примерно раз в минуту).
